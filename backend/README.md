# Backend

This directory is reserved for backend services, APIs, and database integrations for Purva Ocean Adventures.

### Planned Endpoints & Services:
- `POST /api/inquiry`: Handles reservation submissions, guest inquiries, and contact requests sent from the frontend reservation form.
- Email/WhatsApp notification service (e.g., Nodemailer, SendGrid, Twilio/WhatsApp Business API).
- Booking and itinerary management.
